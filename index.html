خطوات إنشاء سيرفر مجاني (مرة وحدة بس، ~5 دقائق):
1. افتح console.firebase.google.com وسجّل بحساب Google.
2. Add project → سمّي المشروع (مثلاً albassit).
3. Build ← Realtime Database ← Create Database → Test mode.
4. ⚙️ Project settings ← General ← Your apps ← </> → انسخ firebaseConfig.
5. الصق الكائن هون ودوس اتصال.
